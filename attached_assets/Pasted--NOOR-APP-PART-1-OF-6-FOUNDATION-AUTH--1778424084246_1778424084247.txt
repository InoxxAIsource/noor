AUTH SYSTEM (server/routes/auth.js)
════════════════════════════════════════
npm install bcryptjs jsonwebtoken nanoid cors helmet

POST /api/auth/register
  Body: { email, name, password }
  - Check email not already taken (email: index)
  - Hash password: bcrypt.hash(password, 10)
  - userId = nanoid()
  - Store user: db.set('users:'+userId, {
      id, email, name, passwordHash,
      madhab: null, sunniMadhab: 'hanafi',
      language: 'en', city: null, lat: null, lng: null,
      goals: [], reminderHour: 7,
      onboardingComplete: false,
      subscriptionStatus: 'free',
      createdAt: Date.now(), lastActive: Date.now()
    })
  - Store index: db.set('email:'+email, userId)
  - Create streak: db.set('streak:'+userId, {
      currentStreak: 0, longestStreak: 0,
      lastPrayerDate: null, weeklyGoal: 5,
      weeklyCompleted: 0, totalPrayers: 0, totalMinutes: 0
    })
  - Return JWT: sign({ userId }, JWT_SECRET, { expiresIn:'30d' })

POST /api/auth/login
  - Get userId from email index
  - Fetch user, bcrypt.compare password
  - Return JWT

GET /api/auth/me (requires auth middleware)
  - Decode JWT, fetch user, return (minus passwordHash)

Auth middleware (server/middleware/auth.js):
  Read Authorization: Bearer {token}
  Verify JWT → attach req.userId
  Return 401 if invalid

Frontend (hooks/useAuth.js):
  Store JWT as 'noor_token' in localStorage
  Decode payload to get userId
  Provide: user, isLoggedIn, logout, refetchUser
  On app load: verify token still valid via GET /api/auth/me

HOME DASHBOARD — Home.jsx

Components top to bottom:

   Show coloured banner:

   Muharram: teal #2a4a6a "Month of Muharram"
   Dhul Hijjah (1-10): green "Days of Hajj"

2. GREETING
   "As-salamu alaykum, {name}!"
   "{weekday}, {HijriDate}"

3. PRAYER TIMES WIDGET
   Fetch: GET https://api.aladhan.com/v1/timingsByCity
   ?city={user.city}&country=IN&method=1
   (method=1 for Hanafi, method=0 for Shia)
   Show: all 5 prayer times
   Show: live countdown to next prayer (updates every second)
   Tap any prayer → mark as prayed (POST /api/salah/log)

4. CRESCENT ANIMATION (CrescentAnimation.jsx)
   SVG crescent moon with gold glow animation
   5 floating gold particles (float-up keyframe)

5. IBADAH STREAK (StreakTracker.jsx)
   Large number: currentStreak
   Label: "day streak 🔥"
   7 small dots: filled green = completed, empty = missed
   Progress ring SVG: weeklyCompleted / weeklyGoal

6. DAILY CONTENT (3 cards in horizontal scroll)
   Today's Name of Allah: Arabic + English meaning
   Today's Hadith: short text (first 100 chars)
   Dua of the day: based on user goals

7. QUICK-START GRID (2×2 session cards)
   Morning Azkar / Evening Azkar / 60s Dua / Quran Reflection
   Each card: title + duration + category icon
   Tap → navigate to /player/:id

8. "What do you need today?" button → /mood

9. TASBIH QUICK-START row
   Three pills: SubhanAllah / Alhamdulillah / Allahu Akbar
   Tap → navigate to /tasbih with that dhikr preset
