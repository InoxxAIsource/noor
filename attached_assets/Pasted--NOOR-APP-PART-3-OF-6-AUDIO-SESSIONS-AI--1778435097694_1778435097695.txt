AUDIO SESSION PLAYER — Player.jsx
════════════════════════════════════════
Route: /player/:id

Fetch session by id from sessions:all in Replit DB.

Layout (full screen, dark):
  Back button (top left)
  Session title (Cinzel font, gold, center)
  Category badge

SCRIPTURE DISPLAY (most important UI element):
  Arabic text (Amiri font, 22px, gold, right-aligned, dir=rtl)
  Transliteration below (italic, green, 14px)
  English meaning below (white, 14px)
  This is the core value prop — Arabic + meaning together

AUDIO CONTROLS (Howler.js):
  If session.audioUrl exists:
    Play/pause button (large, green circle)
    Seek bar with progress percentage
    Current time / total duration
    Speed selector: 0.75x / 1x / 1.25x / 1.5x
    Background sound toggle: 🌧 Rain / 🔇 Silence
      (NO music — keep halal, use rain/water ambient only)
  If audioUrl is null:
    Show: "Audio coming soon — read along below"
    "Mark as complete" button

Howler.js setup:
  const sound = new Howl({
    src: [session.audioUrl],
    html5: true, // streaming
    onplay: () => setPlaying(true),
    onend: () => handleComplete(),
    onload: () => setDuration(sound.duration())
  })

Save progress every 30 seconds:
  POST /api/progress with { sessionId, durationListened }

ON SESSION COMPLETE:
  1. Confetti animation (gold particles burst)
  2. "Alhamdulillah! Ibadah logged." message
  3. Mood check-in:
     "How do you feel now?"
     8 mood chips (same as mood page)
     Compare with moodBefore (ask at session start)
  4. AI Journal prompts (3 questions from Claude)
     Display as 3 tappable chips above text area
  5. Journal text area (500 char limit)
  6. Save journal: POST /api/journal
  7. [Gift this dua] button → opens share modal
  8. Related sessions (3 cards based on category)

AI MOOD RECOMMENDATION
════════════════════════════════════════
Route: POST /api/ai/recommend (server/routes/ai.js)
Auth required.

Server steps:
1. Fetch all sessions from sessions:all
2. Fetch last 3 user progress entries
3. Extract recent session titles
4. Call Claude API:

const response = await fetch('https://api.anthropic.com/v1/messages', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': process.env.ANTHROPIC_API_KEY,
    'anthropic-version': '2023-06-01'
  },
  body: JSON.stringify({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 400,
    system: 'You are Noor app\'s dua recommendation engine. Return ONLY valid JSON. No markdown. No explanation.',
    messages: [{
      role: 'user',
      content: `User feels: ${mood} at intensity: ${intensity}.
Recent sessions (avoid repeating): ${recentTitles.join(', ')}.
Pick the 3 best matching sessions from this list.
Give one warm specific reason (under 20 words) for each.
Sessions: ${JSON.stringify(sessions.map(s=>({id:s.id,title:s.title,category:s.category,tags:s.tags})))}
JSON: {"recommendations":[{"id":"...","title":"...","reason":"..."},{"id":"...","title":"...","reason":"..."},{"id":"...","title":"...","reason":"..."}]}`
    }]
  })
})

5. Parse JSON from response.content[0].text
6. Fetch full session data for each recommended id
7. Return { recommendations: [{session, reason}] }

LIVE PRAYER ROOMS
════════════════════════════════════════
Pages: Rooms.jsx (list) + Room.jsx (live room)
Uses Server-Sent Events (SSE) — no WebSockets needed.

Rooms.jsx (/rooms):
  "Create a room" button (top right)
  List of active rooms:
    Session title + participant count + host name
    Pulsing green dot (live indicator)
    [Join] button

  Create room modal:
    Session dropdown (all sessions)
    Room name input
    On submit: POST /api/rooms
    Returns: { code: 'NOOR-7K' }
    Show: "Share this code: NOOR-7K"
    Copy button + WhatsApp share

Room.jsx (/room/:code):
  GET /api/rooms/:code → fetch room data
  
  SSE connection: new EventSource('/api/rooms/:code/stream')
  Handle events:
    participant_joined → update count
    intention_added → add to intentions list
    playback_start → start Howler.js playback
    participant_left → update count

  Layout:
    Room name (top)
    Participant count: "🕌 12 souls praying together"
    Session title + [▶ Start] (host only)
    Intentions feed (scrollable):
      Each: sender name + intention text + prayer count
      [🤲 Pray for this] → increment count via API
    Add intention: text input + submit

SSE Server (server/routes/rooms.js):
  Store active room connections in memory:
    const roomConnections = {} // { code: [res1, res2...] }
  
  GET /api/rooms/:code/stream:
    Set headers: Content-Type: text/event-stream
    Add res to roomConnections[code]
    Send: data: {"type":"connected","count":room.participantCount}\n\n
    On client disconnect: remove from roomConnections[code]
  
  Broadcast helper:
    function broadcast(code, event) {
      const conns = roomConnections[code] || []
      conns.forEach(res => res.write(`data: ${JSON.stringify(event)}\n\n`))
    }
  
  POST /api/rooms/:code/join:
    Increment participantCount in DB
    broadcast(code, { type:'participant_joined', count })
  
  POST /api/intentions:
    Add intention to room.intentions[]
    broadcast(code, { type:'intention_added', intention })

API routes:
  POST /api/rooms — create room, generate code
  GET /api/rooms/active — list live rooms
  GET /api/rooms/:code — room details
  POST /api/rooms/:code/join
  GET /api/rooms/:code/stream — SSE
  POST /api/intentions
