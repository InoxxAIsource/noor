QURAN READER
════════════════════════════════════════
Pages: Quran.jsx (surah list) + QuranSurah.jsx (reader)

Quran.jsx (/quran):
  List all 114 surahs in order

  Search bar to filter by name

QuranSurah.jsx (/quran/:number):
  Fetch surah data from quran.com API (free):
    GET https://api.qurancdn.com/api/qdc/verses/by_chapter/{number}
    ?words=true&translation_fields=text&per_page=286
  Display each ayah:
    Arabic text RIGHT-ALIGNED (font: Amiri, 22px, color: #ffd700)
    dir="rtl" lang="ar" on Arabic elements
    English translation below (16px, color: #c8e8c8)
    Ayah number circle
    Tap play icon → fetch + play audio:
      URL: https://everyayah.com/data/Alafasy_128kbps/
           {surah3digits}{ayah3digits}.mp3
      Example: Surah 2, Ayah 255 = 002255.mp3
    Tap Arabic word → tooltip with word meaning
  Bookmark button per ayah
  Continue reading: save lastSurah + lastAyah in localStorage
  Progress bar: ayahsRead / totalAyahs

QIBLA COMPASS
════════════════════════════════════════
Page: Qibla.jsx (/qibla)

Calculate Qibla bearing (mathematical, works offline):
  Kaaba: lat=21.3891, lng=39.8579
  User GPS: navigator.geolocation.getCurrentPosition
  Formula: bearing = atan2(sin(Δlng)×cos(lat2),
    cos(lat1)×sin(lat2) - sin(lat1)×cos(lat2)×cos(Δlng))

Use DeviceOrientationEvent to get compass heading.
Qibla direction = bearing - deviceHeading

Display:
  Animated SVG compass rose
  Green arrow pointing to Qibla
  Degrees shown (e.g. "267° NW")
  Distance to Kaaba in km
  "Kaaba is {X}km away"
  Permission request for device orientation

Fallback (if no orientation): show static bearing only

MASJID FINDER
════════════════════════════════════════
Page: MasjidFinder.jsx (/masjid-finder)

npm install leaflet react-leaflet

Get user location → query OpenStreetMap (FREE, no key):
  POST https://overpass-api.de/api/interpreter
  Body (text/plain):
  [out:json];
  node["amenity"="place_of_worship"]["religion"="muslim"]
  (around:5000,{lat},{lng});
  out;

Display:
  Leaflet.js map (OpenStreetMap tiles):
    Green mosque pins
    User location blue dot
  List below map:
    Mosque name + distance in km
    [Navigate] → opens "https://maps.google.com/maps?daddr={lat},{lng}"
  Filter chips: All / Sunni / Shia / Jama Masjid
  "Favourite masjid" star button → saves to user record
  Saved favourite shows at top of home screen

API route:
  GET /api/masjid/nearby?lat=&lng=
    Server calls Overpass API
    Returns array of { name, lat, lng, distance }
  POST /api/masjid/favourite — save masjid to user
  GET /api/masjid/favourite — get user's favourite

ZAKAT CALCULATOR
════════════════════════════════════════
Page: ZakatCalculator.jsx (/zakat-calculator)

Input fields (all in INR):
  Cash (bank + hand)
  Gold value → show: "Current gold price: ₹{price}/gram"
    Fetch: GET https://api.metals.live/v1/spot/gold
    Convert troy oz to grams: ÷ 31.1035
    Convert USD to INR: × 83 (or fetch live rate)
    OR: manual grams input × price per gram
  Silver value
  Business inventory
  Investments / shares
  Money owed TO you
  MINUS: your debts

Calculation button → show results:
  Total zakatable wealth: ₹{amount}
  Nisab threshold (87.48g gold × price): ₹{nisab}
  BIG YES/NO: "✓ Zakat is obligatory on you"
    OR "✗ You are below nisab — no zakat due"
  If yes: Zakat due = 2.5% = ₹{amount}
  Breakdown table showing each asset contribution
  "Donate your zakat" section with links:
    Islamic Relief India / Human Appeal / Edhi Foundation

Save calculation → remind next year (store zakatDate in user)

API route:
  GET /api/zakat/gold-price
    Fetch from metals.live, convert to INR/gram, return
